# StudyBuddy – ključne funkcionalnosti

| #   | Funkcionalnost                                | Opis                                                                                                                                                                                                                  | Kje v kodi                                                                                                                  |
| --- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| F1  | **Registracija in prijava**                   | Uporabnik ustvari račun (e-pošta, ime, geslo ≥ 8 znakov) in se prijavi. Gesla so shranjena kot bcrypt hash, seja je JWT žeton (7 dni). Ob poteku žetona je uporabnik samodejno odjavljen.                             | `server/src/routes/auth.js`, `server/src/middleware/auth.js`, `client/src/pages/LoginPage.jsx`, `client/src/utils/auth.jsx` |
| F2  | **Izolacija podatkov med uporabniki**         | Vsak uporabnik vidi in spreminja le svoje podatke; dostop do tujega vira vrne 404.                                                                                                                                    | `server/src/routes/helpers.js` (`findOwned`, `assertCourse`)                                                                |
| F3  | **Upravljanje predmetov**                     | Dodajanje, urejanje, brisanje predmetov (ime, koda, ECTS, profesor, barva). Izbris predmeta kaskadno izbriše njegove obveznosti, zapiske in ocene. Pri predmetu je prikazano povprečje in število odprtih obveznosti. | `server/src/routes/courses.js`, `client/src/pages/CoursesPage.jsx`                                                          |
| F4  | **Upravljanje obveznosti**                    | Naloge, izpiti in projekti z rokom, prioriteto in opisom; dodajanje, urejanje, brisanje.                                                                                                                              | `server/src/routes/assignments.js`, `client/src/pages/AssignmentsPage.jsx`                                                  |
| F5  | **Sledenje stanju in filtriranje obveznosti** | Stanja _za narediti / v teku / opravljeno_; filtriranje po stanju, predmetu, vrsti in zamujenih; razvrščanje po roku; zamujene so označene.                                                                           | `assignments.js` (GET s filtri, PATCH `/status`)                                                                            |
| F6  | **Pomodoro časovnik**                         | Odštevanje 25 ali 50 minut s pavzo; ob koncu se seja samodejno shrani, ob predčasni prekinitvi se shrani dejansko pretečen čas (≥ 1 min).                                                                             | `client/src/components/StudyTimer.jsx`, `client/src/pages/StudyPage.jsx`                                                    |
| F7  | **Beleženje sej učenja**                      | Ročni vnos seje (začetek, trajanje, predmet, opomba), zgodovina sej s skupnim časom, filtriranje po obdobju, brisanje.                                                                                                | `server/src/routes/sessions.js`, `StudyPage.jsx`                                                                            |
| F8  | **Zapiski s iskanjem**                        | Zapiski po predmetih; ustvarjanje, urejanje, brisanje; iskanje po naslovu in vsebini (z zamikom 300 ms).                                                                                                              | `server/src/routes/notes.js`, `client/src/pages/NotesPage.jsx`                                                              |
| F9  | **Ocene in povprečja**                        | Vnos ocen (lestvica 5–10) z utežmi; uteženo povprečje po predmetu in skupno povprečje, uteženo z ECTS (predmeti brez ocen se ne upoštevajo).                                                                          | `server/src/routes/grades.js`, `server/src/services/grades.js`, `client/src/pages/GradesPage.jsx`                           |
| F10 | **Pregledna plošča**                          | Število odprtih in zamujenih obveznosti, 5 najbližjih rokov z "dni do roka", seznam zamujenih, graf minut učenja po dnevih tekočega tedna.                                                                            | `server/src/routes/dashboard.js`, `server/src/services/stats.js`, `client/src/pages/DashboardPage.jsx`                      |
| F11 | **Validacija vnosov in obravnava napak**      | Vsi vnosi se preverijo z Zod shemami; napake vrnejo 400 s seznamom polj, ki jih uporabniški vmesnik prikaže. Neveljaven JSON → 400, neznana pot → 404.                                                                | `server/src/errors.js`, `client/src/utils/api.js`                                                                           |

## Uporabniški tok (primer)

1. Uporabnik se registrira in prijavi (F1).
2. Doda predmete za semester (F3).
3. Vnese obveznosti z roki (F4) in jim med delom spreminja stanje (F5).
4. Med učenjem uporabi Pomodoro časovnik (F6) ali ročno vnese čas (F7) in si dela zapiske (F8).
5. Po kolokvijih vnese ocene in spremlja povprečje (F9).
6. Na pregledni plošči vidi, kaj ga čaka in koliko se je učil ta teden (F10).
